# Quest episode 按键

本机 `robot-record` 的手动采集和混合模式使用以下按键，左右镜像不改变它们的作用：

Franka、Nero、Flexiv 使用同一个录制状态机。当前模式是启动程序后立即开始
第一段；A/B 控制段的保存或重录，不是“开始/停止整个程序”的开关。
镜像模式下 A/B 仍是全局按键，不随左右手映射交换，也不用于开关夹爪。

| 按键 | 流程 |
| --- | --- |
| A | 结束当前 episode，先保存，再执行 `robot.reset()`，成功后自动开始下一 episode。 |
| B | 丢弃当前未保存的 episode，清空它的帧和临时图像，再执行 `robot.reset()`，成功后自动重录。 |

无需再按键盘右箭头。B 不删除之前已保存的 episode，也不增加已完成 episode 数量。
A 遇到空段不写入空 episode；达到配置的 episode 数量后结束采集。
长按只触发一次，松开后才可再次触发；A/B 同时按下时优先丢弃。

按键帧不执行普通遥操作动作，reset 过程不计入数据。按住 A/B 时会清空手柄位姿增量参考，
松开后重新建立参考，避免将回位期间的手柄位移补发给机械臂。

B 原有的“右夹爪交回策略”功能已取消，不再兼任夹爪控制。其他夹爪扳机功能保持原样。
保留键盘原有的结束、重录和退出流程；键盘结束 episode 后仍可等待下一段启动。

保存失败会退出，不继续 reset；reset 失败不会继续开始下一段。
已经成功保存了 episode 的数据集，在异常退出或 Ctrl+C 时保留，不再提示删除整个目录。
混合模式的 success 标注仍依照所选 `success_policy`；显式人工标注模式仍会按配置询问。

修改后重新启动本机 `robot-record` 生效，无需重启 NUC server。
已通过模拟设备和真实临时 LeRobot 数据集测试，未驱动真实机械臂验证按键流程。
